1. コメント(※)

・※から行末まではコメントであり、SPDの構造・処理としては解釈しない。
・コメントは生成コードの対応する位置に // コメントとして転記する。
・引用符("…")・鉤括弧(「…」)内の※はコメント開始とみなさない。
・※だけの行は構造解析上は存在しないものとして扱う(縦線の連結を切らない)。

税込み価格の計算(※による1行コメント)
│
├─変数int priceにキーボードから価格を入力する ※税抜き価格
│  ※ここからは税込み価格の計算と表示
└─priceに1.1を掛けて整数に丸め、"税込=〇〇"の形式で表示する

import jp.kwebs.tools.Input;
public class Example1 {
    public static void main(String[] args) {
        int price = Input.getInt(); // 税抜き価格

        // ここからは税込み価格の計算と表示
        System.out.printf("税込=%d%n", Math.round(price * 1.1));
    }
}

            default -> System.out.println("内部エラー");
        }
    }
}

エラーコードの判定(switch式、ブロック)

import jp.kwebs.tools.Input;

for文

  • インデックス付きfor文
ループ変数を使って指定回数繰り返すfor 文
│
└─↻─for: 3 回繰り返す
   │
   └─ループ変数と"Hello" を空白で区切って表示する

public class Example2_3_1 {
    public static void main(String[] args) {
        for (int i = 0; i < 3; i++) {
            System.out.println(i + " Hello");
        }
    }
}
  • 拡張for文
拡張for 文
│
├─整数のリストを作成して、変数listに代入する
│        └──list ← [10, 20, 30]
│
└─全ての要素を表示する─↻─for: n ← list
                         │
                         └─ nをコンソールに表示する

import java.util.List;
public class Example2_3_2 {
    public static void main(String[] args) {
        var list = List.of(10, 20, 30);

        for (var n : list) {
            System.out.println(n);
        }
    }
}
  • 拡張for文でのリスト処理
リストの要素を集計する(拡張for 文、集計処理)
│
├─準備┬─整数のリストを作成して、変数listに代入する
│      │        └──list ← [10, 20, 30]
│      └─合計を入れる変数int total を宣言してゼロを代入する
│
├─合計を計算する─↻─for: n ← list
│                 │
│                 └─ nをtotal に加算する
│
├─平均を計算する
│        ├─total をdoubleにキャストしてlistの要素数で割ってaverageに代入する
│        └─average を小数点以下1 桁までに四捨五入して、averageに再代入する
│
└─結果を表示する┬─合計(total )を "合計＝〇〇" の形式でコンソールに表示する
                  └─平均(average )を "平均＝〇〇. 〇" の形式でコンソールに表示する

import java.util.List;
import jp.kwebs.tools.Tools;
public class Example2_3_3 {
    public static void main(String[] args) {
        var list = List.of(10, 20, 30);
        int total = 0;

        for (var n : list) {
            total += n;
        }

        double average = (double) total / list.size();
        average = Tools.round(average, 1);

        System.out.printf("合計＝%d%n", total);
        System.out.printf("平均＝%.1f%n", average);
    }
}
  • 拡張for文でのオブジェクトのリストの処理
オブジェクトのリスト(拡張for 文、オブジェクトのリスト)
│
├─Product クラスのインスタンスのリストを作る
│    └─products ← (new Product(MT890, ステンレスネジ, 280, false),
│                     new Product(MT810, タッピングネジ, 160, true),
│                     new Product(MT900, スクリューネジ, 330, true) )
│
└─productsの要素を表示する
      └─↻─ for: p ← products
         │
         └─商品名(p.name)と価格(p.price )をコロンとタブで区切って表示する

import java.util.List;
public class Example2_3_4 {
    public static void main(String[] args) {
        var products = List.of(
            new Product("MT890", "ステンレスネジ", 280, false),
            new Product("MT810", "タッピングネジ", 160, true),
            new Product("MT900", "スクリューネジ", 330, true)
        );

        for (var p : products) {
            System.out.println(p.name + ":\t" + p.price);
        }
    }
}

while文

  • 無限ループのパターン
電卓プログラム(while 文、無限ループのパターン)
│
├─変数int total を宣言しゼロを代入する
├─合計を計算する──↻─while: true
│                   │
│                   ├─変数int numberにキーボードから整数を入力する
│                   ├─◇─numberは0 である
│                   │          └─ breakでループを脱出する
│                   ├─numberをコンソールに表示する
│                   └─total に─を加算する
│
│
└─結果の表示┬─終了時の区切りとして"------"を表示する
              └─ "合計= 〇〇" の形式でtotal を表示する

import jp.kwebs.tools.Input;
public class Example2_3_5 {
    public static void main(String[] args) {
        int total = 0;

        while (true) {
            int number = Input.getInt();
            if (number == 0) {
                break;
            }
            System.out.println(number);
            total += number;
        }

        System.out.println("------");
        System.out.printf("合計= %d%n", total);
    }
}
  • 実行文を含む条件判定
電卓プログラム(while 文、入力して条件判定のパターン)
│
├─準備┬─変数int total を宣言しゼロを代入する
│      └─変数int numberを宣言する
│
├─合計を計算する
│      └─↻─while: numberにキーボードから整数を入力し、それが0 でない間繰り返す
│         │
│         ├─number をコンソールに表示する
│         └─totalに─を加算する
│
├─終了時の区切りとして"------"を表示する
└─ "合計= 〇〇" の形式でtotal を表示する

import jp.kwebs.tools.Input;
public class Example2_3_6 {
    public static void main(String[] args) {
        int total = 0;
        int number;

        while ((number = Input.getInt()) != 0) {
            System.out.println(number);
            total += number;
        }

        System.out.println("------");
        System.out.printf("合計= %d%n", total);
    }
}

3. ファイル入出力処理と例外処理

3.1 リストの出力

  • リストの一括出力
リストをテキストファイルに一括書き出しする(例外処理)
│
├─準備┬─整数のリストを作る──list ← [10, 20, 30]
│      └─変数var path ← output.txtのパス
│
└─一括出力─〇─ try
              │    └─リストをoutput.txtに一括出力する
              │
              〇─catch: IOException e
                    └─"ファイル出力エラー" と表示する

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;
public class Example2_3_7 {
    public static void main(String[] args) {
        var list = List.of("10", "20", "30");
        var path = Path.of("output.txt");

        try {
            Files.write(path, list);
        } catch (IOException e) {
            System.out.println("ファイル出力エラー");
        }
    }
}
  • リストを1行ずつ出力する
行単位のファイル書き出し(例外処理、リソース付きtry 文)
│
├─準備┬─リストを作って変数listに代入する：list ← [10, 20, 30]
│      └─path ← output.txtのパス
│
└─１行ずつ書き出す─〇─try: path によりPrintWriter を作って変数out に代入する
                      │  └─↻─for: listから毎回１要素を取り出して変数lineに代入する
                      │      │
                      │      └─ out.printlnでlineを出力する
                      │
                      〇─catch: IOException e
                          └─ "ファイル出力エラー" と表示する

import java.io.IOException;
import java.io.PrintWriter;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;
public class Example2_3_8 {
    public static void main(String[] args) {
        var list = List.of(10, 20, 30);
        var path = Path.of("output.txt");

        try (var out = new PrintWriter(Files.newBufferedWriter(path))) {
            for (var line : list) {
                out.println(line);
            }
        } catch (IOException e) {
            System.out.println("ファイル出力エラー");
        }
    }
}

4.1 クラスメソッド

クラスメソッド：mile2km
│
├─目的：マイルを距離に変換する
├─引数
│    └─double mile：マイルの値
├─戻り値
│      └─double： キロメートルの値
│
└─処理
      ├─マイルをキロメートルに変換する
      │      ├─km = mile * 1.609
      │      └─km = km を小数点以下2 桁までに四捨五入する
      └─ km を返す

import jp.kwebs.tools.Tools;
public class Example4_1 {

    /**
     * マイルを距離に変換する
     * @param mile マイルの値
     * @return キロメートルの値
     */
    public static double mile2km(double mile) {
        double km = mile * 1.609;
        km = Tools.round(km, 2);
        return km;
    }
}

│

│
├─メソッド：membership_fee　　　　　※インスタンスメソッドと同義
│  │
│  ├─目的：会費額を返す
│  ├─引数：なし
│  ├─戻り値: int 、会費の額　　　　※戻り値型と戻り値の説明を読み点で区切って書く
│  └─処理
│        └─FEE の値を返す
│
│※※※※※　クラスメンバの記述は、まとめておくと見やすい　※※※※※※
│
├─クラス変数：
│  └─会費額：# final int FEE = 5000　　※会議の基本月額
│
├─クラスメソッド: doSomethig
│  │
│  ├─目的：クラスメソッドの例を示す
│  ├─引数：なし
│  ├─戻り値：なし
│  └─処理
│        └─※詳細を省略（何かの処理を書く）
│
└─クラスメソッド：main　※mainメソッドは、目的、引数、戻り値を省略してよい
    │
    └─処理
          ├─（100, "田中宏" ）でインスタンスを作って変数memberに代入する
          └─memberをコンソールに表示する

import java.util.Objects;
// 会員を表すクラス
public class Member {

    protected static final int FEE = 5000; // 会費額 (会議の基本月額)

    private int uid;     // 番号
    private String name; // 名前

    // 自動生成：コンストラクタ：引数なし
    public Member() {
    }

    // 自動生成：コンストラクタ（全引数）
    public Member(int uid, String name) {
        this.uid = uid;
        this.name = name;
    }

    // 自動生成：ゲッター
    public int getUid() {
        return uid;
    }

    public String getName() {
        return name;
    }

    // 自動生成：セッター
    public void setUid(int uid) {
        this.uid = uid;
    }

    public void setName(String name) {
        this.name = name;
    }

    // 自動生成：toString
    @Override
    public String toString() {
        return "Member[uid=" + uid + ", name=" + name + "]";
    }

    // 自動生成：等値判定 ← uid
    @Override
    public boolean equals(Object obj) {
        if (this == obj) {
            return true;
        }
        if (!(obj instanceof Member other)) {
            return false;
        }
        return uid == other.uid;
    }

    @Override

// CSV 文字列を生成する
public class Joining {

    private String csv;       // CSV 文字列
    private String delimiter; // 区切り文字

    // 自動生成：コンストラクタ（全引数）
    public Joining(String csv, String delimiter) {
        this.csv = csv;
        this.delimiter = delimiter;
    }

    // 引数が1 つのコンストラクタ
    public Joining(String delimiter) {
        this.csv = "";
        this.delimiter = delimiter;
    }

    // 引数のないコンストラクタ
    public Joining() {
        this.csv = "";
        this.delimiter = ",";
    }

    // 自動生成：ゲッター
    public String getCsv() {
        return csv;
    }

    public String getDelimiter() {
        return delimiter;
    }

    /**
     * CSV 文字列に新しい文字列を連結する
     * @param s 追加する文字列
     */
    public void add(String s) {
        if (csv.isEmpty()) {
            csv = s;
        } else {
            csv = csv + delimiter + s;
        }
    }
}
