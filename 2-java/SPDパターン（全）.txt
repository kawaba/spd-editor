※拡張for文
拡張for 文
│
├─整数のリストを作成して、変数listに代入する
│        └──list = [10, 20, 30]
│
└─全ての要素を表示する─↻─for: n ← list
                         │
                         └─ nをコンソールに表示する

※拡張for文でのリスト処理
リストの要素を集計する(拡張for 文、集計処理)
│
├─準備┬─整数のリストを作成して、変数listに代入する
│      │        └──list = [10, 20, 30]
│      └─合計を入れる変数int total を宣言してゼロを代入する
│
├─合計を計算する─↻─for: n ← list
│                 │
│                 └─ nをtotal に加算する
│
├─平均を計算する
│        ├─total をdoubleにキャストしてlistの要素数で割ってaverageに代入する
│        └─average を小数点以下1 桁までに四捨五入して、averageに再代入する
│
└─結果を表示する┬─合計(total )を "合計＝〇〇" の形式でコンソールに表示する
                  └─平均(average )を "平均＝〇〇. 〇" の形式でコンソールに表示する

※拡張for文でのオブジェクトのリストの処理

│    └─products = (new Product(MT890, ステンレスネジ, 280, false),
│                    new Product(MT810, タッピングネジ, 160, true),
│                    new Product(MT900, スクリューネジ, 330, true) )
│
└─productsの要素を表示する
      └─↻─ for: p ← products
         │
         └─商品名(p.name)と価格(p.price )をコロンとタブで区切って表示する
